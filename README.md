# Ulf TV (Android TV IPTV-app)

En ren och färdig grundapp för Android TV som bygger automatiskt på GitHub utan att du behöver ändra i koden.

## Så får du ut din APK-fil (3 steg)

1. **Ladda upp till GitHub:** Packa upp den här zip-filen på datorn. Skapa ett nytt repo på GitHub (eller rensa ditt gamla) och ladda upp alla filer och mappar (inklusive `.github`-mappen).
2. **Ladda ner APK:n:** Gå till fliken **Actions** på GitHub. Vänta cirka 1–2 minuter tills bygget blir grönt, klicka på det och ladda ner **`Ulf-TV-APK`** längst ner under *Artifacts*.
3. **Installera på TV:n:** Packa upp `Ulf-TV-APK` för att få `app-debug.apk`, för över den till din Android TV och installera. Öppna appen, klicka på **M3U-länk / Inställningar** och klistra in din M3U-länk.
